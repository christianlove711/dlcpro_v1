# AD9269纯PL UDP网络与协议说明

## 网络

- FPGA：`192.168.20.2`
- PC专用网卡：`192.168.20.1/24`
- 控制/状态：UDP `5000`
- 原始数据：UDP `5001`
- PS/DLC pro继续使用另一网段，不与PL高速采集网卡混用。

PL协议不实现完整操作系统网络栈，因此不响应 ARP/ICMP；`ping` 失败不等于板卡离线。GUI使用 `/24` 广播发现，并校验回复源地址、事务号和 `stream_id`。

20 MSPS双通道原始ADC有效载荷约80 MB/s。建议：

1. Realtek千兆有线网卡直连；
2. 链路协商为1 Gbit/s全双工；
3. 长时间20 MSPS使用9014 Bytes Jumbo Packet；
4. 关闭会抢占该网卡的无关协议和节能功能；
5. HDF5写入高速SSD，避免慢U盘造成录制队列拥塞。

## 协议与质量计数

DAQD包携带 `packet_sequence` 和 `first_sample_index`：

- 包序号空洞表示网络或PC接收丢包；
- 首样点索引空洞表示PL组包前监视路径丢样；
- 两者同时发生时以真实样点索引计算总空洞，避免重复统计。

界面状态：

- `网络丢包`：PC检测到UDP包序号空洞；
- `PL监视丢样`：FPGA监视路径来不及组包的真实ADC样点；
- `录制队列丢样`：本机后台HDF5写入速度不足；
- `ADC/网络空洞窗口`：自动锁频分析窗口包含索引空洞，该窗口作废且禁止写DLC pro。

## 示波器显示

短时基可显示点或普通波形；长时基可选1 ms min/max包络以保留窄透射峰。包络只用于显示和自动峰值历史，不改变原始样点、HDF5文件或网络计数。
