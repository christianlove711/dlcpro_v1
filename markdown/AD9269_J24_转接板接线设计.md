# AD9269 双通道 ADC 到皓月 ZYNQ-7020 J24 转接板接线设计

## 1. 设计结论

该方案适用于商家 AD9269-20/80 双通道 16 bit 模块的 2x14 数字接口，以及皓月 ZYNQ-7020 底板 J24 2x20 扩展接口。

- AD9269 两个通道复用同一组 `D[15:0]`，不需要 32 根数据线。
- `DCO` 的两个边沿分别承载两个通道的数据，FPGA 端使用 `IDDR` 采集并拆分通道 A/B。
- 模块手册说明该模块数字输出配置为 3.3 V CMOS，可与 J24 所在的 3.3 V PL I/O 直接连接。
- J24 的可用 PL 引脚数量足够容纳 16 位数据、DCO、采样时钟、OTR 和 SPI/控制信号。
- `DCO` 分配到 Bank 13 的时钟能力引脚 `U10`，`CLK` 分配到配对的 `T9`。

## 3. J24 其余针脚

| J24 针脚 | 信号 | 处理方式 |
|---|---|---|
| 5、6 | 3V3 | 不连接到 AD 模块接口，禁止误接 CLK/DCO |
| 7、8 | D8、D5（PS MIO） | 不连接；不是普通 PL XDC 引脚 |
| 15、16 | GND | 接转接板完整地平面 |
| 27、28 | GND | 接转接板完整地平面 |
| 37 | V5，Bank 13 PL I/O | 预留测试/触发信号 |
| 38 | U15，Bank 34 PL I/O | 预留；不要加入 AD9269 高速总线 |
| 39、40 | GND | 接转接板完整地平面 |

## 4. 电源与保护

1. J24 的 1、2 脚并联后接模块 1、2 脚，使用宽线或铜皮供电。
2. J24 所有 GND 脚都接连续地平面；模块 3、4 脚连接同一地平面。
3. 模块接口附近放置 `100 uF` 电解或固态电容、`1 uF` 和 `0.1 uF` 陶瓷电容，均接在 5 V 与 GND 之间。
4. 可在 5 V 入口预留 `0.75 A~1 A` 自恢复保险丝和电源指示灯；正式定值应以模块实测最大电流为准。
5. 不增加电平转换器。若实物模块并非手册所述的 3.3 V CMOS 版本，应先停止上电并重新核对。
6. 不热插拔转接板或 ADC 模块。

## 5. PCB 布线要求

- 推荐 4 层板：Top 信号、GND、5 V/辅助信号、Bottom 信号。20 MSPS 验证可使用布线良好的 2 层板，但不建议把它当作 80 MSPS 最终版本。
- J24 与 AD9269 接口尽量靠近，数据路径建议小于 50 mm。
- `DCO` 是最关键网络，避免过孔和支路，旁边保持连续参考地。
- `D[15:0]` 相对 `DCO` 的长度差：20 MSPS 目标控制在 10 mm 内；若准备运行 80 MSPS，建议控制在 5 mm 内。
- `CLK` 单独走线，不要长距离平行贴近 `DCO`；两者虽在同一 P/N 引脚对上，但均按单端 LVCMOS33 使用。
- SPI 和 PDWN/OEB 可以低速布线，但不要穿过 DCO 与数据总线区域。
- 不在转接板上默认重复增加数据串联电阻；先依据模块原理图确认模块端已有的阻尼网络。需要调试时，可只为 FPGA 输出的 `CLK/SCLK/CSB/OEB/PDWN` 预留 0 Ω/22 Ω 可替换焊盘。
- 增加 `5V`、`GND`、`DCO`、`CLK` 测试点，以及 J24 37、38 两个预留脚测试点。

## 6. 接插件和方向

- J24 侧使用与底板实际母座/公座相配的 2x20、2.54 mm 接插件。
- AD9269 侧使用与模块实际接口相配的 2x14 接插件。
- 原理图和 PCB 丝印必须同时标注：`PIN 1`、`+5V`、`GND`、模块朝向。
- 两块板面对面插接时，PCB 顶视图可能左右镜像。画封装时必须依据针脚编号连网，不能依据截图的视觉左右位置连线。
- 首次装配先不插 ADC 模块，用万用表确认模块接口 1/2 脚为 5 V、3/4 脚为 GND，且 5 V 与 GND 无短路。

## 7. FPGA 接口定义

建议顶层端口如下：

```verilog
input  wire [15:0] adc_data;
input  wire        adc_dco;
input  wire        adc_otr;
output wire        adc_clk;
output wire        adc_pdwn;
output wire        adc_csb;
output wire        adc_oeb;
inout  wire        adc_sdio;
output wire        adc_sclk;
```

建议的 XDC 数据位映射为：

```text
D0=V6, D1=W6, D2=V8, D3=W8,
D4=W10, D5=W9, D6=V11, D7=V10,
D8=Y12, D9=Y13, D10=Y7, D11=Y6,
D12=Y9, D13=Y8, D14=W11, D15=Y11,
DCO=U10, CLK=T9, PDWN=U5, OTR=T5,
CSB=V7, OEB=U7, SDIO=U8, SCLK=U9
```

所有这些 AD 总线端口使用 `LVCMOS33`。`DCO` 的时钟周期约束按准备支持的最高采样率设置：20 MSPS 为 50 ns，80 MSPS 为 12.5 ns。最终输入延迟约束还需依据 AD9269 的 DCO/data 时序和实际 PCB 延迟补齐。

## 8. 上板验证顺序

1. 不插 ADC，验证转接板电源和短路情况。
2. 插 ADC 后只上电，确认 5 V 和模块各路稳压正常。
3. FPGA 固定输出 `PDWN=0`、`OEB=0`、`CSB=1`，以最低采样率输出 CLK。
4. 用 ILA 先观察 DCO 是否连续，再观察 D[15:0] 是否变化。
5. 通过 SPI 写入模块数字测试码，验证 16 位位序与双边沿 A/B 通道拆分。
6. 最后接入两个模拟通道，并用不同频率或不同幅值确认通道没有互换。
