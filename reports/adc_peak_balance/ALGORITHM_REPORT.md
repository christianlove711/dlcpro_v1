# ADC原始码00模自动找峰算法报告

## 1. 控制目标与设备边界

算法读取PL UDP环形历史中的AD9269原始有符号ADC码，只调节DLC pro的
`Scan Offset`与`Scan Amplitude`。扫描输出必须是`PC Voltage`（通道50，单位V），
扫描波形必须是三角波。自动流程不会修改扫描频率、输出通道、波形或任何FALC增益、
滤波和范围参数。

依据`Manual.md`，`laser1:scan:enabled`控制扫描开关，扫描只能在激光未锁定时开启；
FALC Main和Unlim分别由`falc1:main:enabled`与`falc1:unlim:enabled`控制。

## 2. 峰识别与不均匀度

每次决策使用4个完整扫描周期的1 ms min/max原始码历史。背景取中位数，噪声取
`1.4826 × MAD`，峰门限为用户最小峰高与噪声倍率门限中的较大值。最强重复峰组
与第二候选峰组的突出度比低于用户门限时，窗口标记为“00模候选不唯一”。这表示
当前窗口不能可靠区分00模和其它峰，不等于没有透射峰。

三角扫描每周期两次穿越00模。连续穿越的交替间隔为`Δt1`和`Δt2`，实测周期为：

```text
T_peak = Δt1 + Δt2
```

要求它与`1 / Scan Frequency`相差不超过10%。中心不均匀度定义为：

```text
E = |Δt1 - Δt2| / (Δt1 + Δt2)
```

`E=0`表示两次穿越完全等间隔，即透射峰位于三角扫描中心。

## 3. Offset方向控制

每次方向试探冻结以下基准：试探前Offset、试探前不均匀度、方向和步长。同时保存
本轮历史最佳Offset、最佳不均匀度和对应峰观测。后续判断始终与该固定基准比较，
不会把每个新窗口覆盖为下一步参考。

判定死区为：

```text
margin = max(0.5个百分点, 参考不均匀度 × 5%)
```

- 新不均匀度低于`参考-margin`：接受当前方向，并更新最佳点。
- 新不均匀度高于`参考+margin`：恢复最佳点，方向反转，步长减半。
- 位于死区：再取一个独立4周期窗口；连续两次无明确改善后反向并减半。

下一步即将越过`启动Offset ± 最大允许偏移`时，不再停在单侧边界。算法从最佳Offset
向相反方向试探并减半步长。两侧均受限时先恢复最佳Offset；只有恢复可靠Amplitude后
仍无法找到唯一00模，才安全停止并输出完整范围和最佳点信息。

## 4. 无效窗口与候选歧义恢复

- Offset试探后候选不唯一：本次试探判为失败，从最佳点反向。
- Amplitude缩小后候选不唯一：恢复上一级可靠Amplitude。
- 尚无00模指纹：围绕启动Offset执行`+1、-1、+2、-2`对称搜索。
- ADC索引空洞：整批窗口作废，期间绝不写DLC pro。
- 扫描频率变化超过2%：清空方向证据和确认计数，重新建立4周期窗口。

Offset写入读回后先丢弃2个完整稳定周期，再采集另外4个周期；Amplitude写入后丢弃
3个周期，再采集另外4个周期。稳定期数据不能参与方向判断。

## 5. 阶梯缩幅与FALC接管

各幅度阶段使用界面中可配置的不均匀度门限、Offset步长、缩幅比例和连续确认窗口。
达到最终目标Amplitude后，必须连续3个完全独立窗口通过最终不均匀度、峰身份、周期
和数据完整性检查，才能接管FALC。

双路径接管顺序固定为：

```text
Scan Off → 校验 → Main On → 校验 → Unlim On → 校验
```

任一步失败时回滚本次使能的FALC路径，Scan保持关闭，防止半锁定后重新扫频。

## 6. 诊断日志

每次自动决策记录状态、Amplitude、Offset、`Δt1`、`Δt2`、当前与参考不均匀度、
判定结果、方向、步长和目标读回。无效窗口记录最强/第二候选ADC码、强度比及门限、
实测周期、是否存在历史00模指纹，以及随后执行的恢复动作。

板测报告应保留完整日志，并重点确认：错误方向能自动反转、单侧边界不再停止、
候选不唯一能够恢复，以及FALC严格按Main后Unlim的顺序接管。
