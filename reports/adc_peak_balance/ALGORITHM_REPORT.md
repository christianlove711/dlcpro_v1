# ADC 原始码 00 模两级自动锁定算法

> 当前实现日期：2026-08-07
>
> 实现入口：`daq_pc/adc_peak_balance_algorithm.py`、`daq_pc/adc_peak_balance_controller.py`
>
> 本文描述 ADC 采集页面中的单透射信号算法，不是主控制台的双信号三策略自动锁频模块。

## 1. 目标、依据与限制

算法读取 PL UDP 环形历史中的 AD9269 原始有符号 ADC 码，只使用透射峰，自动调节 DLC pro 的 `Scan Offset` 和 `Scan Amplitude`。

设备前提来自 `Manual.md`：

- Scan Output 必须是 `PC Voltage`（通道 50，单位 V）；
- Scan Shape 必须是 `Triangle`（设备值 1）；
- `Scan Offset` 是直流中心，`Scan Amplitude` 是叠加在中心上的扫描幅度；
- 扫描只能在激光未锁定时开启；
- FALC Main 与 Unlim 分别由 `falc1:main:enabled` 和 `falc1:unlim:enabled` 控制。

峰识别、理论跳转、Offset 搜索顺序和自动验收是本项目算法，不是 TOPTICA 官方自动锁定算法。单透射信号无法从物理上绝对保证区分载波与所有边带；强度比、周期一致性和历史指纹只能降低误锁风险，真实 FALC 接管仍必须在有人监护下验证。

## 2. 启动与初始化

观察模式不写 DLC pro，使用设备当前频率、Amplitude、Offset 和 Scan 状态。自动控制模式按以下顺序初始化：

1. 检查 ADC 与 DLC pro 已连接、扫描频率为正、波形为三角波、输出为 PC Voltage。
2. 如果当前选中 FALC 路径已经使能，拒绝强行开启扫描。
3. 将扫描频率切换到“快速扫频频率”，默认 `10 Hz`。
4. 将 Scan Amplitude 切换到“初始化扫频范围”，默认 `2.5 Vpp`。
5. 如果 Scan 关闭，则开启 Scan 并校验读回。
6. 从写入完成后的新 ADC 索引开始采集。

频率读回允许设备量化误差：容差为 `max(0.001 Hz, 目标频率 × 10 ppm)`，后续分析始终使用设备实际读回值。

如果初始化窗口连续两次没有透射峰，Amplitude 保持 `2.5 Vpp`，Offset 围绕初始化中心按下列顺序搜索：

```text
+1 V, -1 V, +2 V, -2 V, ...
```

搜索遵守 PC Voltage 物理边界，并保证完整三角扫描 `Offset ± Amplitude/2` 不越界。发现第一个有效透射峰后，以该位置重新建立后续 Offset 安全中心，然后进入快速居中。

## 3. ADC 峰识别

每次决策使用 2 个完整扫描周期的 1 ms min/max 历史。写入 Offset 或 Amplitude 后先丢弃 1 个完整稳定周期，再另取 2 个全新周期；稳定期数据和已经分析过的 ADC bin 不会重复用于判断。

检测流程：

1. 从包索引检查窗口是否完整；存在 ADC 索引空洞时整窗作废且不据此验收。
2. 从包络较低的 20% 数据估计基线和 MAD 噪声，避免窄扫共振线本身抬高噪声门限。
3. 峰门限取“最小峰高”和“噪声倍率门限”中的较大值。
4. 使用局部极大值与非极大值抑制分离相邻穿越峰。
5. 比较最强候选族与第二候选族；强度比低于设定值时标记为“00 模候选不唯一”。
6. 使用突出度、峰宽、极性和周期建立并更新历史峰指纹。

三角扫描每周期穿越同一透射峰两次。相邻交替间隔为 `Δt1` 和 `Δt2`：

```text
T_peak = Δt1 + Δt2
E = |Δt1 - Δt2| / (Δt1 + Δt2)
```

`T_peak` 必须与 `1 / Scan Frequency` 一致；`E` 是峰间隔不均匀度，`E = 0` 表示透射峰位于三角扫描中心。

## 4. 快速居中：2.5 Vpp

快速阶段默认要求不均匀度不超过 `8%`，连续通过 2 个独立窗口后，Amplitude 一步缩到最终目标 `0.2 Vpp`。

### 4.1 理论距离

三角波几何关系给出当前峰到扫描中心的电压距离：

```text
D = 0.5 × Amplitude(Vpp) × E
```

算法先做一次 `+0.05 V` 方向试探：

- 不均匀度改善：物理方向为正；
- 不均匀度变差：物理方向为负；
- 变化落在判定死区：再取一个独立窗口，仍不明确才进入有界慢速搜索。

方向确定后，从试探前的原始 Offset 直接跳转：

```text
Offset_target = Offset_origin ± 0.8 × D
```

理论跳转使用 PC Voltage 物理安全范围，不受精调 `±0.5 V` 软件窗口截断。如果 `0.8 × D` 位置的窗口无效或候选不唯一，只额外尝试一次完整 `1.0 × D` 位置；之后才允许退回反向、减半的有界搜索。模型最多按剩余不均匀度直接修正 2 次。

### 4.2 快速阶段验收

当 `E ≤ 8%` 时停止继续移动 Offset，并开始独立窗口计数。连续 2 个新窗口通过后执行：

```text
Scan Amplitude: 2.5 Vpp → 0.2 Vpp
```

不存在宽扫、中扫、细扫、窄扫五级缩幅，也不再按固定比例逐级缩小 Amplitude。

## 5. 最终 Offset 搜索：0.2 Vpp

进入 `0.2 Vpp` 后不再使用理论距离，也不会自动恢复到 `2.5 Vpp`。首窗有效、超差、候选不唯一、周期不一致或与历史指纹不符时，都保持 `0.2 Vpp` 并执行两级离散 Offset 搜索。

两个阶段始终围绕缩到 `0.2 Vpp` 时的同一个中心 `O`，按正负方向交替：

```text
第一级：O+0.001, O-0.001, O+0.002, O-0.002, ...,
        O+0.009, O-0.009 V

第二级：O+0.01, O-0.01, O+0.02, O-0.02, ...,
        O+0.09, O-0.09 V
```

规则如下：

- 任一候选达到最终不均匀度门槛，立即停止遍历并进入连续验收；
- 无效候选只记为失败并继续下一个 Offset，不改变 Amplitude；
- 两级遍历完成仍不达标时，恢复有效候选中的最佳 Offset；
- 如果没有可验收候选，则安全停止并保持 `0.2 Vpp`；
- 不会继续搜索 `±0.1～±0.5 V`，也不会自动扩大 Scan Amplitude。

最终默认门槛为 `E ≤ 5%`、连续 3 个独立窗口。界面允许调整最终门槛和窗口数。

## 6. FALC 接管

最终验收通过后分两种情况：

- 未勾选“达到设定标准后自动使能 FALC pro”：停止自动调节，保持当前 Scan、Offset 和 Amplitude，不再写设备。
- 已勾选自动 FALC：按照当前 FALC Path Selection 接管，不修改增益、滤波、范围或其它 FALC 参数。

双路径接管顺序固定为：

```text
Scan Off并校验 → Main On并校验 → Unlim On并校验
```

使能失败时停止流程并报告读回失败，避免在无法确认状态时继续写入。

## 8. 日志与现场验证

日志记录当前状态、Amplitude、Offset、`Δt1`、`Δt2`、不均匀度、参考值、峰强比、理论距离、方向、目标写入及设备读回。

首次板测应依次进行：

1. 仅观察：确认通道、极性、峰周期和候选身份。
2. 自动调节但不使能 FALC：确认初始化搜索、理论跳转和两级最终 Offset 搜索。
3. 自动 FALC：确认 Scan 关闭以及 Main/Unlim 顺序与读回。

重点检查是否选择了真实 00 模而非边带。自动化测试能够验证状态机和数值边界，但不能替代真实光路、ADC 波形和 FALC 锁定状态验收。
