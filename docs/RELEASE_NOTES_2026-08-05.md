# 发布说明 2026-08-05

## 主要功能

- DLC pro 网络/串口连接，恢复 TCP 命令端口 `1998` 和监控端口 `1999` 配置。
- ADC 采集与主程序统一入口，共享 DLC pro 连接。
- AD9269 5/10/20 MSPS PL UDP 双通道示波器。
- HDF5 单通道录制、可选速率/路径和 DLC pro 扫描元数据。
- 后台 Vivado batch JTAG 下载 bitstream。
- ADC 原始码 00 模识别、Offset方向试探、阶梯缩幅和FALC自动接管。

## 本版自动找峰修正

- 自动模式启动前检查并按需开启 Scan；已有 FALC 锁定时拒绝强行扫描。
- Offset方向判断使用固定试探基准，不再用不断漂移的上一窗口作参考。
- 变差时恢复历史最佳 Offset、反向并减半步长。
- `00模候选不唯一`不再直接停机，按动作来源恢复 Offset 或可靠 Amplitude。
- 单侧 Offset 边界不再停死，恢复最佳点并反向探索。
- Offset/Amplitude 写入后严格使用稳定周期和全新 4 周期决策窗口。
- 决策日志记录当前/参考不均匀度、峰强比、方向和恢复动作。
- 双路径接管顺序改为 `Scan Off → Main On → Unlim On`，逐项读回并支持失败回滚。

## 界面与稳定性

- ADC 通道 A/B 纵轴和显示方式彼此独立。
- min/max 包络改为可选显示。
- 自动锁频支持仅观察模式和人工建议日志。
- 通道 A/B、扫频控制和自动锁频改为真正独立顶层窗口；最小化主窗口不会连带最小化。
- FPGA 下载进度、编码和连接错误提示改进。
- HDF5 写入移出接收关键路径，记录质量计数写入文件。

## 已知边界

- 自动找峰和 FALC 接管已经有自动化测试，但首次真实锁定仍需现场监护。
- 20 MSPS 双通道对网卡和磁盘性能敏感，建议巨帧和高速 SSD。
- FPGA bitstream 不随软件发布，必须单独选择经板测的版本。
- RGMII 外部时序的最终 PCB 长度签核不属于本软件发布范围。
