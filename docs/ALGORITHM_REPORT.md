# ADC 原始码 00 模两阶段自动锁定算法

> 当前实现：2026-08-08  
> 代码：`daq_pc/adc_peak_balance_algorithm.py`、`adc_peak_balance_controller.py`、`adc_peak_balance_window.py`

本文描述 ADC 页面中的单透射信号控制器，不是主 DLC pro 控制台的双信号三策略模块。设备接口以官方 Python SDK 为准，Scan/FALC 行为与安全限制以 `Manual.md` 为准；峰族识别和控制策略属于本项目算法。

## 1. 设备前提

- ADC 与 DLC pro 已连接且 ADC 正在采集；
- Scan Output 为 `PC Voltage`（通道50、单位V），波形为三角波；
- 自动模式启动前，当前 FALC 选中路径不能仍处于使能状态；
- 软件始终限制完整扫描 `Offset ± Amplitude/2` 位于 PC Voltage 物理范围内；
- 自动 FALC 只按已配置 Path Selection 接管，不修改增益、滤波和范围。

## 3. 两周期峰族识别

每次决策只分析写入稳定期之后的两个完整扫描周期。ADC索引必须连续；写入后先丢弃一个稳定周期，再从新bin采集两个周期，旧数据不重复计数。

1. 由低20%包络估计基线和MAD噪声；门槛取“最小突出度”和“噪声倍数”较大者。
2. 一个连续越过门槛的宽峰只算一次物理穿越，宽峰内重复极大值不会生成假峰。
3. 按跨周期重复的两个三角波相位，把四次穿越聚合成物理峰族；不再把高度排名前N和后N强行分组。
4. 选择突出度最强的完整峰族；与第二峰族强度比不足、周期超差、ADC空洞或窄扫主峰低于宽扫参考比例时，Offset原地不动并复测。
5. 峰宽只记录，不作为硬身份指纹。只有连续两个窗口真正没有主峰时，才进入Offset寻峰。

对主峰族交替间隔：

```text
Tpeak = Δt1 + Δt2
有符号误差 e = (Δt1 - Δt2) / Tpeak
不均匀度 E = |e|
```

`Tpeak`相对`1/f`的误差必须在用户门槛内。实测载波约比边带强百倍时，5倍强度门槛保留充分裕量；单透射信号仍不能从物理上绝对证明模态身份，首次板测必须人工确认。

## 4. 宽扫阶段

自动模式写入用户设置的快速频率和初始化Amplitude；观察模式不写设备，始终使用实际读回频率。频率读回容差为：

```text
max(0.001 Hz, 目标频率 × 10 ppm)
```

初始化没有主峰时，Amplitude保持不变，Offset相对启动中心按：

```text
+1步, -1步, +2步, -2步, ...
```

搜索到PC Voltage物理边界即停止。找到主峰且`E`超过宽扫门槛时，只做一次正向方向试探；必要时再做一次负向试探。方向确定后从试探前Offset跳完整理论距离：

```text
D = 0.5 × Amplitude × E
Offset_target = Offset_origin ± D
```

不存在`0.8D → 1.0D`、减半搜索或五级缩幅。跳转后若仍超差，只按剩余误差直接修正，次数受“宽扫理论残差修正次数”限制。达到宽扫门槛后立即停止调Offset，连续达到确认窗口数后一步写入最终Amplitude。

## 5. 最终阶段

从最终Amplitude启动或由宽扫缩入后，禁止使用理论距离，禁止恢复或扩大Amplitude，也不做完整正负网格遍历。

- 离目标较远：按最终粗调步长定向移动；
- 改善：沿同一方向继续；
- 变差或越过最佳点：恢复最佳Offset、反向并切换最终精调步长；
- 接近目标或变化进入死区：切换最终精调步长；
- 所有最终动作限制在缩幅入口Offset的`±最终最大Offset偏移`内；
- 只有连续两个窗口完全没有主峰，才按粗调步长`+1、-1、+2、-2…`重新捕获；Amplitude仍保持最终值。

未勾选自动FALC时，首个有效最终窗口达到门槛便立即停止所有写入。勾选自动FALC时，冻结Offset并连续确认用户设置的窗口数，然后执行：

```text
Scan Off并校验 → Main On并校验 → Unlim On并校验
```

## 6. 日志与自动保存

运行日志只有四种事件：`START`、`MEASURE`、`WRITE`、`END`。等待、建议和稳定期只显示在状态区。

每个`MEASURE`包含频率、Amplitude、Offset、扫描上下界、峰/峰族数量、主/次峰突出度、强度比、SNR、峰宽、理论/实测周期与误差、`Δt1/Δt2`、有符号误差、不均匀度与门槛、参考值、步长、方向、理论距离、动作与目标值。`START`保存本次21项实际参数和设备启动读回；`WRITE`保存请求、读回、容差和结果；`END`保存最终状态。

每次运行逐行刷新并自动保存UTF-8 CSV到：

```text
daq_pc/captures/auto_lock_logs/
```

手动停止、自动达标、故障、断线、窗口关闭和FALC完成都会正常封口文件；运行中暂存文件以`.partial.csv`结尾。

## 7. 验证范围

当前自动测试覆盖21项设置、旧键迁移、100:1载波/边带、宽峰重复极大值、第五次边缘穿越、周期偏差、ADC空洞、无效窗口禁止写Offset、完整理论跳转、最终粗调转精调、最终幅度不扩幅、FALC确认计数和四类CSV事件。虚拟腔可完成宽扫居中、直接缩幅并进入最终锁定。

恢复设备后按三级板测：仅观察；自动调节但不接管FALC；最后在有人监护下测试自动FALC。静态测试和仿真不能替代真实光路与锁定状态验收。
