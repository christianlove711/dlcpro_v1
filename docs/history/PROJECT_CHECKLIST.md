## 本轮验收记录

- 旧版 Auto Lock、旧 Scope、旧预设和旧组件已删除。
- 原 Auto Lock 2 已迁移为唯一 Auto Lock，代码、文件、类、文本键和默认预设均采用无编号命名。
- Auto Lock 当前固定显示 FPGA 双路采集配置；连接、预览和真实锁频路径在协议接入前不可执行。
- 废弃的外部示波器采集依赖及其历史实验入口已移除。
- 窗口首次自适应，后续保存 geometry；缩放不会重置窗口大小、位置和滚动区域。
- 主导航和主要并排区域支持窄窗口重排，所有功能窗口提供可滚动中央区域。
- 设备任务由单线程协调器串行执行，用户操作 FIFO，轮询去重，连续写入按参数合并。
- 快照按核心、可见模块和完整校准分级读取，部分回读与缓存合并为完整快照。
- 用户预设写入 Windows 用户配置目录并原子替换；旧算法预设支持一次迁移。
- Python、Markdown、JSON、SVG 等文本格式已统一 LF；`build/`、`dist/` 和缓存已停止 Git 跟踪。
