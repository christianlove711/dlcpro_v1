# 操作与部署指南

## 1. 启动前检查

1. DLC pro、激光器、FALC 和开发板按实验室安全规程接线并上电。
2. DLC pro 网口与 PC 位于同一网络；直连自动地址通常使用 `/16`。
3. PL 专用网卡固定为 `192.168.20.1/24`，FPGA 为 `192.168.20.2`。
4. 需要下载 FPGA 时连接 USB-JTAG，并确认本机有 Vivado 2020.2。
5. 20 MSPS 双通道优先使用千兆网卡和 9014 Bytes Jumbo Packet。

软件不能替代 DLC pro 的硬件联锁、发射许可和实验室激光安全流程。首次自动接管 FALC 必须有人观察，且应先在“仅观察”模式验证峰识别。

## 2. DLC pro 连接

网络连接填写设备 IP 或系统标签，命令端口使用 `1998`，监控端口使用 `1999`。串口连接选择实际 COM 口，默认 `115200 8N1`。

常见错误：

- `Device not found / WinError 121`：设备未响应，检查地址、网线、设备电源和路由。
- `Error -22: no access`：已经连接，但设备拒绝访问某参数；检查设备型号、模块配置和当前状态。
- 官方软件能连接而本软件不能：先确认端口是 `1998/1999`，再检查是否有其它客户端占用会话。

## 3. ADC 采集

从主界面点击“ADC数据采集”，或以 `python app.py --open-adc` 启动。

1. 选择 5、10 或 20 MSPS。
2. 根据物理接线选择是否交换 A/B；算法通道名称始终与示波器显示名称一致。
3. 点击“发现并连接”，确认实测采样率和 PL 吞吐稳定。
4. 点击 START 后再打开通道 A/B。

通道 A/B、扫频控制和 ADC 自动锁频均为独立桌面窗口。最小化主 ADC 窗口不会连带最小化它们。

### 显示模式

- 点：只画抽取后的显示点，不连线。
- 普通波形：连接显示点，便于观察慢变化。
- min/max 包络：每个像素列显示该时间段的最小值和最大值，用于防止窄峰在长时基抽取时消失。

显示抽取不改变原始采集数据。自动找峰使用带绝对索引的 1 ms min/max 历史，不依赖屏幕 FPS。

## 4. HDF5 录制

录制前选择：

- 通道 A 或 B；
- 1 MSPS、100 kSPS、10 kSPS 或 1 kSPS；
- 仅 ADC 波形，或 ADC 波形 + DLC pro 扫描参数；
- 本地磁盘、移动 SSD 或 U 盘保存路径。

“记录速率”是从 FPGA 实际样点中按 64 位样点索引抽取后写入文件的速率，不会改变 FPGA 的实际采样率。移动介质速度不足可能造成 PC 录制队列丢样，建议先用 100 kSPS 验证，并观察质量计数。

推荐查看工具：HDFView、Python `h5py`、MATLAB 或 LabVIEW。关键数据集见 [AD9269 PC端说明](../daq_pc/README_AD9269.md)。

## 5. ADC 00模自动锁频

自动流程只使用选定透射通道的原始 `int16` ADC 码，不使用误差信号。控制量是 PZT 的 `PC Voltage` 扫描偏置与峰峰值幅度。

首次使用：

1. DLC pro 和 ADC 均已连接并开始采集。
2. 扫描输出为 `PC Voltage`，波形为三角波，频率为合法正值。
3. 确认初始化扫频范围和 Offset 搜索不会超过设备及当前光路的安全范围。
4. 勾选“仅观察算法判断”，确认通道、极性、峰强和建议方向合理。
5. 取消“仅观察”，暂不启用自动 FALC 接管，验证错误方向能自动恢复并反向。
6. 最后才勾选 FALC 自动接管。

### 自动过程

自动模式默认执行：

1. 将快速扫频频率切换到 `10 Hz`，接受设备读回的微小量化误差。
2. 将 Scan Amplitude 初始化为 `2.5 Vpp`。
3. 若 Scan 关闭则自动开启；若当前选中 FALC 路径已经使能则拒绝强行扫描。
4. 初始化连续两窗无峰时保持 `2.5 Vpp`，Offset 按 `+1、-1、+2、-2… V` 搜索。
5. 找到最强完整主峰族后按 `D = 0.5 × Amplitude × 不均匀度` 计算理论距离，用一次 `0.05 V` 试探判断物理方向，再从试探前 Offset 跳转完整理论距离。
6. 快速阶段连续两窗达到默认 `8%` 后，一步缩到 `0.2 Vpp`。
7. 最终阶段保持 `0.2 Vpp`，距离目标较远时沿改善方向按 `0.01 V` 粗调；变差、过零或接近最佳点后恢复最佳Offset并切换到 `0.001 V` 精调。最终偏移限制为缩幅入口的 `±0.09 V`。
8. 未勾选自动FALC时，首个有效窗口达到最终 `5%` 门槛即停止写入；勾选时冻结Offset并连续确认默认3个窗口后接管。

每次 Offset 或 Amplitude 写入读回一致后先丢弃 1 个完整稳定周期，再用另外 2 个全新周期决策。观察模式绝不写 DLC pro，因此不会自动修改频率、Amplitude、Offset 或 Scan 开关。

单透射峰算法不能从物理上绝对排除边带。首次板测必须结合完整波形、峰强、扫描位置和 FALC 实际锁定状态，人工确认选中的确是 00 模。

周期、峰族置信和ADC数据异常时，Offset原地不动并按用户次数复测；只有连续两个窗口完全没有主峰才允许寻峰。最终阶段不会恢复到 `2.5 Vpp`，也不会执行完整正负Offset网格。自动FALC接管顺序固定为：

```text
Scan Off → Main On → 校验 Main → Unlim On → 校验 Unlim
```

任一步失败会回滚本次已使能路径并停止，不修改现有 FALC 增益、滤波或范围参数。

如果未勾选自动使能 FALC，最终验收通过后软件停止自动调节并保持当前 Scan、Offset 和 `0.2 Vpp`，不会继续修改偏置。

算法页直接显示21项参数，分为“峰识别、宽扫、最终锁定”。旧版本保存的`1 Hz`、`7%`等用户值会自动迁移，不会被新安装默认值覆盖。运行日志只包含`START、MEASURE、WRITE、END`，每次结束自动保存到`daq_pc/captures/auto_lock_logs/`。

## 6. FPGA 下载

ADC 页面选择 `.bit` 后会记忆路径。点击“下载FPGA”时软件在后台调用 Vivado batch 和本机 `hw_server`，自动扫描 Zynq-7000 并显示进度。

下载前确认：

- 板卡上电；
- USB-JTAG 线和驱动正常；
- 没有另一个进程占用硬件服务器或临时文件；
- 选择的是经过验证且与当前硬件匹配的 bitstream。

软件不会覆盖用户选择的 `.bit` 文件，也不会自动生成 XSA/HWH。
