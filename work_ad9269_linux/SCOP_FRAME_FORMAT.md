# `SCOP` 固定 DMA 帧

Scope DMA 每个描述符固定传输 32832 字节：

- 64 字节（16 word）`SCOP` 头；
- 8192 个小端 32 位 A/B 样点对；
- 每个样点对为 `bits[31:16]=B`、`bits[15:0]=A`，均为 `int16`。

| Word | 字段 |
|---:|---|
| 0 | `0x504F4353`（`SCOP`） |
| 1 | 格式版本 |
| 2 | `stream_id` |
| 3 | 帧序号 |
| 4 | ADC 原始采样率（Hz） |
| 5 | 抽取倍数 |
| 6–7 | 窗口首个原始样点的 64 位索引 |
| 8–9 | 触发点的 64 位原始样点索引 |
| 10 | 触发、抽取和 FPS 配置 |
| 11 | 窗口内累计 OTR 标志 |
| 12 | Scope 未武装抑制计数 |
| 13 | Scope 已武装背压丢帧计数 |
| 14 | 样点对数量（8192） |
| 15 | 头长度（64 字节） |

每槽 mmap 步长为 36864 字节，只消费前 32832 字节。抽取为 1 且采样率为
80 MSPS 时，相邻样点仍保持 12.5 ns 的原始时间间隔。
